# Draft Instructions

Attach this file, the client facts sheet, and the approved brief when asking
for a draft. The rules below exist so the gate and the editor can trust what
comes back.

## Hard rules

1. **Client facts come only from the facts sheet.** Prices, phone numbers,
   addresses, staff names, credentials, years in business, and results must
   match it exactly. If you need a client fact that is not there, write
   `[[TODO: <what is needed>]]` instead of guessing.
2. **Every statistic or external claim gets a link to its source** in
   markdown, placed in the same sentence. If you cannot name a real, specific
   source, leave the claim out or write `[[TODO: source for <claim>]]`.
   Never invent studies, surveys, or percentages.
3. **Open with the answer.** The first paragraph answers the target query in
   2-3 sentences (under 80 words) and contains the target query wording.
4. **Use at least one item from "Real stories"** in the facts sheet. If none
   fits, write `[[TODO: first-hand example about <topic>]]`.
5. **Respect "Never say" and "Compliance".** Include required disclaimers
   word for word.
6. **Follow the brief's outline and angle.** Do not add sections for length.

## Style

- Write in the client's voice from the facts sheet.
- Short paragraphs, plain words, concrete specifics over general statements.
- Question-style H2s where they match real searches.
- No filler intros ("In today's fast-paced world"), no summary that repeats
  the article, no "delve", "landscape", "leverage", "game-changer".
- Length is whatever answers the query fully. No word-count target.

## Output

Markdown only: one H1, then the body. No front-matter commentary, no notes to
the editor outside `[[TODO]]` markers.
