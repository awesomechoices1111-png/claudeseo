# Link Building Strategist

Combines three link-earning approaches that used to be separate skills into
one, since they're steps in the same overall workflow rather than unrelated
tools: analyze what you're missing (gap analysis), decide what to run first
(tactic prioritization), and generate the actual outreach material for
whichever tactics apply (outreach templates + digital PR angles).

## Choosing a Mode

- **Competitor gap analysis** (Framework 1-4): the request names competitors
  or provides backlink data exports and asks what's missing, or wants a
  scored/prioritized prospect list with outreach templates. This is the
  default when a domain + competitor set is given.
- **Niche starter playbook** (Framework 5): the request is about a new or
  low-authority domain with no clear competitor backlink data to analyze,
  and wants to know which tactics to run first and get templates for each.
- **Digital PR angle generation** (Framework 6): the request is specifically
  about newsworthy story angles, data campaign ideas, or journalist pitches
  - independent of any gap analysis.

Given a domain and competitors, run Framework 1-4 in sequence. Given a niche
and domain with no competitor data, run Framework 5, which points into
Framework 6 if a digital PR angle is worth developing. Given a request
specifically about PR/journalist angles, jump straight to Framework 6.

## Framework 1: Competitor Backlink Gap Analysis

The fastest path to high-quality links is finding where your competitors get
links that you do not. If a site linked to two of your competitors, they've
already shown willingness to link to your category - your job is to give
them a reason to add you.

### Step 1: Establish the Competitor Set

Identify 3-5 true competitors - domains that target the same keywords, serve
the same audience, and sit in the same product or content category. Avoid
sites too large to replicate (their authority isn't instructive), too small
(their link profile isn't instructive), or in adjacent categories.

### Step 2: Classify Every Linking Domain

**Gap Opportunity (Priority 1)**: links to 2+ competitors but not you. They
actively cover your category and you're missing from their coverage - high
probability of success.

**Competitive Opportunity (Priority 2)**: links to 1 competitor but not you.
They've shown willingness to link to this space; needs a stronger pitch.

**Already Won**: links to you already. Nurture for additional links or
mentions.

**Out of Reach**: links to a competitor but has drastically higher DA -
likely a feature or acquisition story, not replicable through standard
outreach.

### Step 3: Gap Analysis Output

```
BACKLINK GAP ANALYSIS: [Target Domain] vs. [Competitors]
TARGET: [yourdomain.com] | COMPETITORS: [comp1.com] | [comp2.com] | [comp3.com]

TIER 1 GAPS (link to 2+ competitors, not you)
Domain | DA | Links to | Link type | Page linking from | Gap opportunity

TIER 2 GAPS (link to 1 competitor, not you)
[same format]

ALREADY WON
[domains + pages - candidates for additional link nurturing]

GAP SUMMARY
Tier 1 gaps: [N] | Tier 2 gaps: [N] | Estimated reachable links: [N]
Top linking domain types: [Resource pages / Listicles / Editorials / Directories]
```

## Framework 2: Opportunity Scoring

Not all links are equal - a single DA 80 link outweighs 50 links from DA 20
directories. Score every prospect before building the outreach list.

Score 5 dimensions, 1-5 each (total 5-25; Tier A 20-25, Tier B 14-19, Tier C
5-13):

1. **Domain Authority** - 5: DR/DA 70+, 4: 50-69, 3: 30-49, 2: 15-29, 1: under 15
2. **Topical Relevance** - 5: core topic, 4: adjacent, 3: broad, 2: loosely related, 1: unrelated
3. **Traffic Quality** - 5: high organic traffic in your category's SERPs down to 1: minimal
4. **Link Accessibility** - 5: resource pages/directories that actively add links, down to 1: no external links policy
5. **Competitor Overlap** - 5: all 3+ competitors linked here, down to 1: no category-related links at all

```
OPPORTUNITY PRIORITY LIST: [Target Domain]

TIER A (20-25) - pursue first
Rank 1: [Domain] | Score [X/25] | DA [X] | linking page [URL] | link type [see Framework 3]
  | outreach contact [see Framework 4] | pitch angle [see Framework 4] | effort [Low/Med/High]

TIER B (14-19) - build in parallel   [same format]
TIER C (5-13) - batch or deprioritize [minimal detail]

PRIORITY SUMMARY
Tier A: [N], ~15-30% conversion | Tier B: [N], ~5-15% | Tier C: [N], ~1-5%
```

## Framework 3: Link Type Classification

Mismatching the pitch to the link type is the most common reason outreach
fails. Seven types, each with a different approach:

| Type | How to get it | Pitch approach | DA potential | Scalability |
|---|---|---|---|---|
| Editorial/Mention | Be citation-worthy (data, research, unique take); pitch journalists/bloggers | "We have [data] your readers would value" / "You covered [competitor], here's why we're worth mentioning too" | Highest | Low |
| Guest Post | Find sites with contributor programs; pitch article ideas | Specific idea + credentials + audience fit | Medium-high | Medium |
| Resource Page | Find "best X tools/resources" pages; ask to be added | "Your resource page on [topic] - we'd be a great fit" | Variable | High |
| Directory/Listing | Claim/submit listings (G2, Capterra, associations) | Self-serve submission | Medium | Very high |
| Broken Link | Crawl competitor backlinks for 404s; offer replacement | "Found a broken link on [page] pointing to [dead URL] - we have a similar resource that might work" | Inherited from page | Medium |
| Unlinked Mention | Monitor brand mentions (Alerts, Ahrefs); ask for a link | "Noticed you mentioned [Brand] - could you add a link to [URL]?" | Same as mentioning page | Medium |
| Partnership/Ecosystem | Integration partners, agencies, co-marketing | Relationship conversation, not cold outreach | High | Low |

```
LINK TYPE BREAKDOWN: [Target Domain]
Editorial/Mention: [N] | Effort: High | Guest Post: [N] | Effort: Medium
Resource Pages: [N] | Effort: Low-Medium | Directories: [N] | Effort: Low
Broken Links: [N] | Effort: Medium | Unlinked Mentions: [N] | Effort: Low
Partnerships: [N] | Effort: Low if relationship exists

RECOMMENDED MIX FOR 90-DAY CAMPAIGN
Quick wins (now): [easiest-access types] | Core program: [scalable type at volume]
High-value pursuits: [editorial/partnership targets worth investing in]
```

## Framework 4: Outreach Contact Strategy and Pitch Angles

Every pitch needs three elements: relevance (why them specifically), value
(what they/their audience gets), and ask (one clear, small request).

| Link type | Who to contact | Channel | Follow-up |
|---|---|---|---|
| Editorial/Mention | Article author, or editor/content lead | Email first, LinkedIn DM backup | 1 follow-up at day 5-7, max 2 touches |
| Guest Post | Managing editor / "write for us" form | Submission form or direct email | 1 follow-up at day 7-10 |
| Resource Pages | Site owner/webmaster | Email/contact form | 2 follow-ups (day 5, day 10) |
| Broken Links | Site owner/webmaster | Email | 1 follow-up at day 5, keep brief |
| Unlinked Mentions | Author of the mentioning page | Email or LinkedIn DM (warm) | 1 follow-up at day 5 |

**Pitch structure:**
```
Subject: [Specific, references their content/site]
Hi [First name],
[Relevance: 1 sentence showing you know their site/content]
[Value: 1-2 sentences on what you bring their audience]
[Ask: 1 clear, low-friction request]
[Optional credibility signal: customers, data, press]
Thanks, [Your name]
```

**By scenario:**
- Gap Opportunity: "Noticed [site] covered [competitor] in [article]. We do [complementary thing] for [audience] - happy to share why [differentiator] might be worth including."
- Resource Page: "Came across your [topic] resource page - we help [audience] with [problem]. Here's a 1-line description: [+ URL]."
- Broken Link: "Found a broken link on your [page] - [dead URL] returns a 404. We have a similar resource at [your URL] that might work as a replacement. No pressure either way."
- Unlinked Mention: "Saw you mentioned [Brand] in your piece on [topic] - thanks. Would you add a link to [URL]? Makes it easier for readers to find us."
- Guest Post: "I write about [topic] and noticed [site] publishes contributed pieces. I have an idea for '[Specific title]' covering [what] for [audience]. Would this fit?"

```
OUTREACH PLAN: [Target Domain] - 90-Day Campaign
WEEK 1-2 QUICK WINS: [Unlinked mentions + Resource pages] | [N contacts] | Goal [N links]
WEEK 3-6 CORE OUTREACH: [Broken links + Resource pages at scale] | [N contacts]
  | Day 0 initial, Day 6 follow-up 1, Day 12 follow-up 2 | Goal [N links]
WEEK 7-12 EDITORIAL + GUEST POST: [N contacts, curated] | Goal [N links]

TRACKING: Prospect | DA | Type | Contact | Date sent | Follow-up 1 | Follow-up 2 | Status | Link won
SUCCESS METRICS: Links won target | DA improvement expected | Anchor text mix target
```

Always prioritize ruthlessly - 50 high-probability Tier A prospects beats 500
mediocre ones.

## Framework 5: Niche Starter Playbook (No Competitor Data)

Use when there's no competitor backlink data to analyze - a new or
low-authority domain that needs a tactic-prioritized starting plan instead.

### Step 1: Get the inputs
Niche/industry, target domain (and roughly its authority/age), existing
content assets worth linking to (data, tools, original research), and
constraints (time, budget, in-house vs. agency).

### Step 2: Prioritize tactics by situation
- **New/low-authority domain**: broken link building and guest posting are
  most accessible (less dependent on the site already trusting you); HARO
  works if there's genuine expertise to offer.
- **Established domain with strong content assets** (data, tools, research):
  digital PR is highest-leverage - editorial links from PR often outperform
  manual outreach at scale. Hand off to Framework 6.
- **Time-constrained, needs quick wins**: broken link building has the
  fastest cycle and highest cold-outreach response rate since it does the
  site owner a favor.
- **Ongoing/ambient**: HARO and journalist requests work best as a standing
  weekly habit, not a one-time push.

State the recommended order and why, given the specific inputs.

### Step 3: HARO / journalist request angle templates
Give 2-3 angles: a data/stat angle (leads with a number), a
contrarian/expert-opinion angle, and a brief quotable-soundbite angle.
Respond within hours, under 150 words, lead with the quote/answer not a bio.

### Step 4: Guest post pitch template
Subject line options, an opening that shows you've read their site (not
generic), 2-3 specific topic ideas tailored to content gaps on their site,
and a soft close. Target sites with real relevance and traffic - not link
farms.

### Step 5: Broken link building template
Identify a broken/dead link on a relevant resource page, confirm the target
domain has (or can create) a genuine replacement, then pitch the fix: brief,
helpful-first tone, states the exact broken link found, offers the
replacement.

### Step 6: Digital PR framing (light touch)
Flag whether the domain has or could create a link-worthy asset (original
data, a free tool, a notable study). If so, note that a full Framework 6 pass
is worth running - don't duplicate the full brainstorm here.

**Output**: prioritized tactic list with reasoning first, then only the
template sections for tactics that weren't deprioritized in Step 2.

## Framework 6: Digital PR Angle Generation

Find genuinely newsworthy angles - not marketing claims dressed up as news -
and turn them into campaign concepts and pitch templates editors would
actually consider.

### Step 1: Get the inputs
Brand/product, industry, any existing data the company has (usage data,
survey capability, proprietary insight), target markets/publications, and
the goal (pure link building vs. also brand awareness/traffic).

### Step 2: Generate story angles
Use only categories that genuinely fit:
- **Original data/survey findings** - a stat or trend nobody else has
  published (highest link-earning potential; genuinely citable)
- **Trend jacking** - connecting brand expertise to a current news trend
  with a genuinely useful expert take
- **Contrarian/myth-busting** - challenging a common industry assumption
  with evidence
- **Ranking/index** - a shareable ranked list or index using available or
  commissionable data
- **Human interest/behind-the-scenes** - a genuine story about the people,
  founding, or process (works for smaller brands without data resources)
- **Reactive commentary** - positioning a spokesperson as the go-to expert
  quote when relevant news breaks

Reject angles that are really just product promotion with a news wrapper -
editors see through it immediately and it damages the relationship for
future pitches.

### Step 3: Score newsworthiness
Score each angle on: timeliness (why now), surprise/counter-intuitiveness,
data credibility (sample size, methodology, recency), visual/shareable
potential (chart/map/graphic-ready), and scale/relatability (broad enough
audience for the target publications). Flag angles that are interesting
internally but too niche or promotional to land real coverage.

### Step 4: Data campaign concepts (if applicable)
Propose 1-3 concepts: what data would be analyzed, the likely headline
finding direction (without assuming a specific outcome), and the shipping
format (interactive tool, downloadable report, simple stat roundup).

### Step 5: Journalist pitch template
Subject line options (lead with the finding, not the company name), a 2-3
sentence body stating the newsworthy angle immediately, one supporting
stat/quote, and a clear offer (full data set, spokesperson availability,
exclusive embargo for a top-tier target).

### Step 6: Publication targeting
Recommend publication/journalist types (trade press, national business
press, local press, vertical outlets, newsletter writers) matched to the
angle's actual scope - don't recommend top-tier national press for a narrow,
niche-specific angle.

**Output**: angles ranked by newsworthiness score with one-line reasoning
each, then the top 1-2 developed further with a full campaign concept and
pitch template, then publication targeting notes.

## How to Run This Skill

1. Given a domain + competitors: run Frameworks 1-4 in sequence.
2. Given backlink data exports (Ahrefs, Semrush, Moz): process against
   Framework 2's scoring, classify by Framework 3, output the prioritized
   list.
3. Given a domain and niche/topic only, no competitor data: run Framework 5,
   which routes into Framework 6 if a PR angle is worth developing.
4. Given a request specifically about digital PR / journalist angles: run
   Framework 6 directly.
5. Given a question about one specific link type ("how do I get guest
   posts"): answer from that type's row in Framework 3 plus the matching
   contact strategy in Framework 4.
