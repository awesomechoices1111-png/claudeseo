# Intent Classification Guide

## The Four Intent Types

### Informational
User wants to learn something. No immediate purchase decision.
- Signals: how to, what is, why does, guide, tips, examples, tutorial
- Best format: How-to guide, definition article, listicle, ultimate guide
- Word count: 1,200-5,000+ depending on topic depth
- Monetization: Display ads, lead magnets, email capture, affiliate links

### Navigational
User is looking for a specific website or page.
- Signals: brand name + login, [brand] pricing, [tool] dashboard
- Content action: Ensure the brand's own pages rank; these are rarely content brief candidates
- Note: If a user asks for a brief on a navigational keyword, clarify whether they want to rank for a branded term or inform users about the brand

### Commercial Investigation
User is researching before buying. Evaluating options.
- Signals: best, top, vs, review, alternative, compare, worth it
- Best format: Comparison article, roundup/listicle, in-depth review
- Word count: 2,000-5,000 depending on number of options reviewed
- Monetization: Affiliate links, lead gen, product demos

### Transactional
User is ready to buy or sign up.
- Signals: buy, pricing, discount, free trial, download, hire
- Best format: Landing page, product page, pricing page
- Word count: 800-1,500 (reduce friction; conversion-focused)
- Monetization: Direct revenue

---

## Dual-Intent Keywords

Some keywords carry both informational and commercial intent. These require special handling.

**Examples:**
- "email marketing software" — user may want to learn or compare
- "SEO audit" — user may want to understand or hire
- "project management tools" — user may want a guide or a recommendation

**How to handle dual-intent in the brief:**
1. Note the dual intent in the brief header
2. Structure the article to serve both intents:
   - Opening sections: informational (what it is, why it matters)
   - Middle sections: commercial (comparison, features, pricing)
   - Closing sections: recommendation + CTA
3. Recommend a longer word count (top end of both ranges)

## Funnel Stage Mapping

| Funnel Stage | Description | Keyword Examples | CTA Type |
|-------------|-------------|-----------------|----------|
| TOFU (Top of Funnel) | Awareness; user doesn't know solution | "how to improve website traffic" | Subscribe, download |

| BOFU (Bottom of Funnel) | Decision; ready to act | "Semrush vs Ahrefs pricing" | Buy, sign up |

## Content Format Decision Tree

```
Is the keyword a question starting with "how to"?
  YES → How-to guide or tutorial
  NO  ↓

Does it contain "best", "top", or comparison words ("vs")?
  YES → Comparison / roundup / best-of listicle
  NO  ↓

Does it start with "what is" or "define" or end with "meaning"?
  YES → Definition / glossary article
  NO  ↓

Is it a branded keyword with clear purchase intent?
  YES → Landing page or pricing page
  NO  ↓

Default → Informational guide (H2-heavy structure)
```

## Audience Sophistication Signals

### Beginner
- Uses generic terms, not technical jargon
- Asks "what is" questions
- Needs definitions and context before advice
- Brief implication: include definitional H2s, avoid assumed knowledge

### Intermediate
- Knows the basics, wants to go deeper
- Uses some technical terms
- Asks "how to improve" or "how to do X better"
- Brief implication: skip basics, focus on tactics and nuance

### Expert / Practitioner
- Uses industry-specific terminology
- Asks about edge cases, advanced configurations, benchmarks
- Brief implication: high H3 density, data-heavy, no hand-holding
