# Competitor Gap Analysis Guide

## Purpose

Competitor gap analysis identifies what the top-ranking pages cover and — more importantly — what they miss. Content that fills these gaps has a structural advantage over existing results.

---

## The Three-Layer Gap Framework

### Layer 1: Topic Gaps
Entire subtopics or sections that no competitor covers.
- These become your differentiated H2s
- Often the highest-value gaps (no competition for the specific subtopic)

### Layer 2: Depth Gaps
Topics competitors mention briefly but don't develop.
- These become more detailed H3 sections than the competition
- Target with longer word counts and more specific semantic keywords

### Layer 3: Angle Gaps
Topics covered, but from the wrong audience angle (e.g., all competitors write for marketers; no one writes for freelancers).
- These require reframing existing topics, not new topics
- Powerful for breaking into competitive SERPs with a differentiated perspective

---

## Gap Analysis Process

### Step 1: Identify Top Competitors
Use the primary keyword in Google. Note the top 5-7 organic results (exclude ads, featured snippets, and Google-owned properties).

### Step 2: Extract Heading Structures
For each competitor URL, extract:
- H1 title
- All H2 headings
- All H3 headings

This can be done with browser DevTools (Ctrl+F for h2, h3 tags) or SEO browser extensions.

### Step 3: Build the Gap Matrix

Create a table with competitor URLs across the top and topics down the left column.

| Topic / Subtopic | Competitor 1 | Competitor 2 | Competitor 3 | Gap Type |
|-----------------|-------------|-------------|-------------|----------|
| Basic definition | Yes | Yes | Yes | Covered — keep brief |
| Step-by-step process | Yes | Partial | No | Depth gap |
| Advanced use cases | No | No | No | Topic gap |
| Beginner mistakes | Partial | No | No | Depth gap |
| Tool recommendations | Yes | Yes | Yes | Covered — must differentiate angle |

### Step 4: Prioritize Gaps

Rank gaps by potential impact:
1. **Topic gaps with search intent** — Topics users clearly want but nobody addresses
2. **Depth gaps in popular sections** — Sections everyone has but covers shallowly
3. **Angle gaps** — Same topic, underserved audience segment

### Step 5: Map Gaps to Brief

Each high-priority gap becomes either:
- A new H2 (for topic gaps)
- An expanded H3 with more depth (for depth gaps)
- A reframed H2 with audience-specific language (for angle gaps)

## Common Gap Patterns by Niche

### SaaS / Tool Content
Common gaps: pricing transparency, integration details, migration guides, use-case-specific walkthroughs for niche audiences.

### E-Commerce / Product Content
Common gaps: specific use cases, comparison with non-obvious alternatives, sizing/compatibility guides, sustainability or ethical sourcing information.

### B2B / Service Content
Common gaps: pricing ranges, timeline expectations, ROI frameworks, case studies by industry vertical.

### Health / Wellness Content (YMYL)
Common gaps: research citations, expert quotes, condition-specific variants, contraindications.

---

## What Not to Steal

Do not copy competitor structures wholesale. The gap analysis finds what is missing, not what to replicate. Your heading architecture should:
- Cover all competitor topics (to match baseline)
- Add your identified gaps (to differentiate)
- Reorder to prioritize your strongest angles (to stand out)
