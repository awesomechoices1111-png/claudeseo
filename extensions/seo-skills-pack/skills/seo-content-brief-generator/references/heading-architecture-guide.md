# Heading Architecture Guide

## Core Principles

Every heading in the brief should earn its place. Ask: "Would a reader scan this heading and immediately understand what value this section provides?" If no, rewrite it.

Headings serve three audiences simultaneously:
1. **The reader** — navigating the page quickly
2. **Google** — understanding the topical scope and depth of the content
3. **The writer** — knowing exactly what to write in each section

---

## H1 Formulas by Content Type

### Informational / How-to
- "How to [Do Target Task] in [X] Steps"
- "How to [Do Target Task]: A Complete Guide"
- "[Target Keyword]: Everything You Need to Know"

### Listicle / Roundup
- "The [X] Best [Category] for [Audience]"
- "[X] [Things/Tools/Ways] to [Achieve Outcome]"
- "Best [Category]: Top [X] Options Compared"

### Comparison
- "[Product A] vs [Product B]: Which Is Better?"
- "[Product A] vs [Product B] — Full Comparison [Year]"

### Definition / Glossary
- "What Is [Term]? Definition, Examples, and Best Practices"
- "[Term] Explained: A Complete Overview"

### Landing Page
- "[Benefit] with [Product/Service]"
- "The [Adjective] [Product] for [Audience]"

## H2 Ordering Principles

Order H2s using one of these logical progressions:

**The Knowledge Ladder** (most common for how-to and guides):
1. What it is / Why it matters
2. Before you start / Prerequisites
3. Step-by-step process
4. Advanced techniques or variations
5. Common mistakes / Troubleshooting
6. FAQ
7. Conclusion

**The Comparison Stack** (for listicles and roundups):
1. How we evaluated options
2. Option 1 (lead with the strongest)
3. Option 2
4. Option 3 ... (continue)
5. How to choose the right option
6. FAQ
7. Conclusion

**The Decision Framework** (for commercial investigation):
1. Overview of the category
2. Key factors to consider
3. Top options with detail
4. Side-by-side comparison
5. Recommendation by use case
6. FAQ

## H3 Usage Rules

Use H3s when a section has 3 or more genuine distinct sub-points.

**Good H3 scenarios:**
- A how-to step with setup, execution, and verification phases
- A tool review with pricing, features, and pros/cons
- A concept with multiple types or variations
- A comparison section with multiple criteria

**Avoid H3s when:**
- The sub-points are just bullet points in disguise
- There are only 1-2 sub-points (use bold text or paragraphs instead)
- The H2 itself is narrow enough to cover in one cohesive section

## Keyword Placement Rules

| Position | Keyword Guidance |
|----------|-----------------|
| H1 | Always include exact primary keyword |
| First H2 | Include primary keyword or close variant where natural |
| Other H2s | Include secondary keywords naturally; avoid forced placement |
| H3s | Use long-tail or semantic keywords; avoid stuffing |
| Opening paragraph | Include primary keyword in first 100 words |

**Keyword variation is fine.** Google understands "content brief", "SEO brief", and "content outline" as semantically equivalent. Do not repeat the exact same phrase in every heading.

## Heading Patterns by Topic Category

### SaaS / Software
```
H1: How to [Use/Implement Product Feature]
H2: What Is [Feature]?
H2: Why [Feature] Matters for [User Type]
H2: How to Set Up [Feature] (Step by Step)
  H3: Step 1: [Setup Action]
  H3: Step 2: [Configuration Action]
  H3: Step 3: [Launch Action]
H2: [Feature] Best Practices
H2: Common [Feature] Mistakes to Avoid
H2: FAQ
H2: Conclusion
```

### Local / Service Business
```
H1: [Service] in [City]: [Benefit Statement]
H2: What to Look for in a [Service Provider]
H2: Our [Service] Process
H2: Why Choose [Business Name/Type]
H2: [Service] Pricing in [City]
H2: Frequently Asked Questions
H2: Get Your Free [Service] Estimate
```

### E-commerce / Product
```
H1: Best [Product Category] in [Year]: Our Top [X] Picks
H2: How We Chose the Best [Products]
H2: Best Overall: [Product Name]
H2: Best for [Use Case]: [Product Name]
H2: Best Budget Option: [Product Name]
H2: How to Choose the Right [Product]
H2: FAQ
```
